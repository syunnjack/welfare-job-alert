# 求人データの入手経路（2026-09-04 時点の調べ）

welfarejob.jp は「条件に合う求人が出たらお知らせする」サイトだが、いま出している
求人カードはすべて表示例で、実在の募集ではない。実データをどう入れるかを調べた。

出典はすべて厚生労働省とハローワークインターネットサービスの公式ページ。
以下の判断は法令の解釈を含むので、**着手前に管轄の労働局へ確認すること。**

---

## 結論を先に

1. **ハローワークの求人は、いまのままでは受け取れない。**オンライン提供の対象は
   地方自治体・公共職業能力開発施設・職業紹介事業者（厚生労働大臣の許可・届出番号
   がある者）に限られている。求人サイトの運営者は対象外。
2. **サイトから自動で取ることもできない。**ハローワークインターネットサービスの
   規約で、システムを解析する行為やシステムに支障を及ぼす行為が禁じられている。
   API による自動取得は、上の対象団体に対して認められた機能。
3. **求人の配信を始めた時点で、こちらに届出の義務が生じる。**メールアドレスを
   集めて求人情報を配信するサービスは「特定募集情報等提供事業」に当たり、事業開始に
   あたって厚生労働大臣への届出が要る（職業安定法第43条の2）。届出は e-Gov 電子申請。
4. **選び方を誤ると、届出では済まず許可が要る。**利用者自身が設定した条件で機械的に
   絞るのは問題ないが、こちらの判断で求人を選んで送ると「職業紹介」に当たる。

---

## 1. ハローワークの求人情報オンライン提供

### 対象

> 地方自治体・公共職業能力開発施設又は職業紹介事業者（厚生労働大臣の許可・届出番号
> がある方）が対象です。

出典: [ハローワーク求人・求職情報提供サービスをご利用の方](https://www.hellowork.mhlw.go.jp/provide/provide_top.html)

募集情報等提供事業者（＝求人サイトの運営者）は、この対象に入っていない。
当サイトは現状ここに当たらないため、**受け取る資格がない。**

### 提供されるもの

CSV 方式と API 方式。項目一覧・仕様書・ダミーデータが公開されている（2026年3月改定版）。
利用には年1回の利用状況報告が要る。

出典: [求人情報オンライン提供 職業紹介事業者ご担当者様へ](https://www.hellowork.mhlw.go.jp/provide/online02.html)

### 受け取れるようにするには

職業紹介事業者になる必要がある。2種類ある。

| | 有料職業紹介事業 | 無料職業紹介事業 |
|---|---|---|
| 手続き | 厚生労働大臣の許可 | 厚生労働大臣の許可（職業安定法第33条） |
| 財産的基礎 | 基準資産額 500万円 ×事業所数<br>現金・預貯金 150万円 ＋（事業所数−1）×60万円 | 大阪労働局のページに記載なし。**要確認** |
| 事業所 | 位置・構造・設備・面積が適切であること。プライバシー保護のため個室やパーティションなどの基準あり | 同上か要確認 |
| 職業紹介責任者 | 事業所ごとに専任。成年後3年以上の職業経験、職業紹介責任者講習の受講（申請日前5年以内） | 同上か要確認 |
| 手数料 | 手数料表を持つこと | 名義を問わず手数料・報酬を一切受け取らない |

出典: [有料職業紹介事業の許可（大阪労働局）](https://jsite.mhlw.go.jp/osaka-roudoukyoku/hourei_seido_tetsuzuki/yuryou_muryou_shokugyou/hourei_seido/kyoka.html)

有料は資産500万円という高い壁がある。無料は手数料を一切取れないかわりに、
財産的基礎の要件が緩い可能性がある。**ここが一番確かめる価値のある点。**
無料職業紹介事業の許可が個人で取れるなら、ハローワークの全求人が API で入る。

---

## 2. 自動取得（スクレイピング）はできない

ハローワークインターネットサービスの規約には、システムまたはセキュリティに支障
または危険を及ぼす可能性のある行為の禁止、およびリバースエンジニアリング等による
解析の禁止がある。API による自動取り込みは、求人情報提供サービスの対象団体に
対して用意された機能であって、一般の利用者に開かれたものではない。

出典: [ハローワーク求人・求職情報提供サービス利用規約](https://www.hellowork.mhlw.go.jp/info/terms_regist01.html)、
[マイページ利用規約](https://www.hellowork.mhlw.go.jp/info/terms.html)

**この経路は取らない。**

## 3. いま作ろうとしているものが、法律上どれに当たるか

### 特定募集情報等提供事業（届出が要る）

> 特定募集情報等提供とは、募集情報等提供のうち、労働者になろうとする者に関する情報を
> 収集して行うものをいいます。
>
> 労働者になろうとする者に関する情報とは、労働者になろうとする特定の個人を識別する
> ことができる情報のほか、個人を特定できない情報であっても、個人の経歴やメール
> アドレス、サイトの閲覧履歴、位置情報等を含むものです。

（令和4年 改正職業安定法Q&A 問1-6）

当サイトはメールアドレスと LINE の宛先を登録してもらい、そこへ求人を配信する設計。
これは正面から当たる。ただし、いまはまだ配信していない。

> メールアドレスを収集していている場合であっても、合同説明会等の一般的なお知らせや
> 当日の入場管理のみに使用し、労働者の募集に関する情報を提供するために利用していない
> 場合（中略）募集情報等提供に利用していないと認められる場合には特定募集情報等提供
> には該当しません。

（同 問1-7）

つまり**求人の配信を始めた瞬間に届出義務が生じる。**

> 労働者になろうとする者を収集して募集情報等提供事業を行う者は、特定募集情報等提供
> 事業者として、事業開始に当たって、厚生労働大臣への届出が必要となります。

（同 問4-1）

届出は e-Gov 電子申請。変更の届出が要るのは氏名・名称、住所、電話番号、許可番号等の
変更時のみ（サービス名やサイトURLの変更では不要）。事業を続ける見込みがなくなった
ときは10日以内に廃止の届出。

出典: [募集情報等提供事業（厚生労働省）](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/boshuujouhouteikyou.html)、
[令和4年 改正職業安定法Q&A](https://www.mhlw.go.jp/content/11600000/000965559.pdf)

### 検索と絞り込みだけなら「収集」に当たらない

> 求人メディア等において利用者が検索ワードを入力した場合や、チェックボックス等で
> 検索結果の絞り込みを行った場合は、労働者になろうとする者に関する情報の収集には
> 該当しません。

（同 問1-6）

サイト上で検索して見るだけの機能なら、届出は要らない。届出が要るのは**宛先を預かって
配信する**部分。いまの「登録は受け付けるが配信はしていない」状態は、この境目の手前にある。

## 4. 届出で済む線と、許可が要る線

職業紹介に当たるのは次のいずれか。

> 1. 求職者情報または求人情報について、仲介する当該者の判断により選別した提供相手に
>    のみ提供を行い、または当該者の判断により選別した情報のみ提供を行うこと
> 2. 求職者情報または求人情報について、当該者の判断により提供相手となる求人者または
>    求職者に応じて加工して提供を行うこと
> 3. 求職者と求人者との間の意思疎通を当該者が中継する場合に、当該者の判断により
>    意思疎通に加工を行うこと

出典: [募集情報等提供と職業紹介の区分](https://www.mhlw.go.jp/stf/shoukaibosyuukubun.html)

**守るべき線**

- 利用者が自分で決めた条件（勤務地・職種・時間帯）で機械的に絞る → 募集情報等提供
- こちらが「この人にはこの求人が合いそうだ」と判断して選ぶ → 職業紹介（許可が要る）
- 特定の利用者の閲覧履歴を踏まえて表示順を変える → 特定募集情報等提供（届出の側）

サイトの文言も揃える必要がある。「あなたに合う求人を選んでお届けします」と書くと、
選別しているように読める。「登録した条件に合う求人をそのままお知らせします」に留める。

## 5. 現実的な選択肢

### 案A: 無料職業紹介事業の許可を取り、ハローワークの API を使う

- 得られるもの: 全国の求人。障害者雇用枠の絞り込みもできる
- 要るもの: 許可申請、職業紹介責任者講習の受講、事業所の要件。財産的基礎は要確認
- 制約: 紹介について手数料・報酬を一切受け取れない。収益はアフィリエイト等に限られ、
  それが「報酬」に当たらないかの確認が要る
- **最初に確かめるのはここ。** 労働局に聞けば1日で分かる

### 案B: 事業主から直接、掲載の依頼を受ける

- 募集情報等提供事業として正面から成立する。届出だけで足りる
- 障害者雇用に絞るなら、特例子会社・就労移行支援事業所・地域の企業から集める
- 数は増えにくいが、他所にない求人になる。サイトの独自性は最も高い

### 案C: 求人メディアの提携・アフィリエイト経由

- 収益設計としては最短だが、多くのASPは成果報酬であって、求人一覧を再掲載する権利を
  与えるものではない。**提携先ごとに規約の確認が要る**
- 「求人を並べる」ことが許されているかを、契約書の条文で確かめてから使う

---

## 6. 次に確かめること（労働局への質問）

1. 無料職業紹介事業の許可に、財産的基礎（基準資産額）の要件はあるか
2. 無料職業紹介事業の事業所要件は、自宅兼事務所でも満たせるか
3. 無料職業紹介事業者が、サイトの広告収入やアフィリエイト収入を得ることは、
   「手数料又は報酬」に当たるか
4. 無料職業紹介事業の許可を得た場合、ハローワーク求人情報のオンライン提供を
   受けられるか（提供対象の「職業紹介事業者」に含まれるか）
5. 利用者が自分で設定した条件で機械的に絞ってメール配信することは、
   「当該者の判断による選別」に当たらないという理解でよいか
